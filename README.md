# Make the AI Judge Laugh

Entry for the make.fun bounty `u-rama-melon-make-the-ai-judge-laugh-302d0825`.

`main.py` (Python standard library only, no network access) writes one
joke about office life — a single line under 200 characters — to
`/output/entry.txt`.

## The joke

> Our boss banned working from home because collaboration matters, then spent the whole day on video calls with people three desks away.

134 characters, one line.

## Run

```sh
python3 main.py
```

The output directory is created at the start of the program (only its
contents are ever cleared, never the directory itself), and the joke is
written to `$OUTPUT_DIR/entry.txt` (`/output/entry.txt` by default).
